**The Ninth Meridian Archive** — a curiosity engine. The program deposits a small archive about an object that should not exist: a brass orrery recovered from a ship that came home forty-one years after it left, engraved with a coastline no chart has ever shown, still ticking though nobody has ever wound it.

The archive is built to make a reader curious, and to reward the curiosity it creates. START-HERE.txt poses three unanswered questions. Five exhibits each explain one thing and withhold another; two of them contradict each other about a date, and a margin note accuses one of being a forgery. Each exhibit carries an ARCHIVE MARK — one word — and the five marks in order are the key that unseals SEALED.txt, which answers the archive's central question and replaces it with a larger one. An index lists the documents that should exist but do not. A conservator's addendum, written in 1987 and marked "not to be catalogued", is catalogued anyway.

Everything is generated deterministically by one dependency-free Node program: same files, same bytes, every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then read `out/START-HERE.txt` — and try not to stop there.
